# التهيئة التكيفية للجامعة

## الهدف

المنصة لا تفترض أن كل الجامعات تملك الصفحات والأنظمة نفسها. عند إنشاء مستأجر جديد يجب اكتشاف الأنظمة والواجهات الموجودة ثم اختيار ما ستديره المنصة وما ستربطه فقط.

## دورة الربط

```text
مصدر الجامعة
  -> موصل الهوية
  -> موصل الأنظمة الأكاديمية
  -> سجل الخدمات والصفحات
  -> اكتشاف البيئة
  -> مطابقة البيانات
  -> اختيار الوحدات
  -> تفعيل الواجهات
```

## سياسة عدم الاستبدال

وجود خدمة مثل الحضور أو الجداول في جامعة ما لا يعني أن المنصة تستبدلها. لكل وحدة ثلاثة أوضاع:

- `platform`: الجامعة تستخدم الوحدة التي تديرها المنصة.
- `external`: الجامعة تستخدم نظامها الحالي والمنصة تربط به.
- `hidden`: الوحدة غير متاحة لهذا المستأجر.

## التخصيص البصري

يُحفظ لكل مستأجر:

- الشعار.
- الألوان.
- الخطوط.
- اسم الجامعة.
- النطاق أو النطاق الفرعي.
- الصفحات المفعلة.
- ترتيب التنقل.
- نصوص الهوية.

## مبدأ مهم

الاكتشاف لا يمنح صلاحيات ولا يقرأ بيانات حساسة لمجرد اكتشاف البيئة. يجب أن تكون موصلات الاكتشاف مصادقًا عليها ومحددة النطاق، وتعيد فقط metadata اللازمة للتهيئة.
