# حالة التنفيذ الحالية

هذه النسخة تضيف الأساس البرمجي لنموذج صلاحيات متعدد المستأجرين وحالة الطالب والتهيئة التكيفية للجامعة.

## تم تأسيسه

- نموذج مركزي للأدوار والصلاحيات.
- تقييد الذكاء الاصطناعي على الطالب النشط فقط ضمن الدور الطلابي.
- صلاحيات المدرس للمجموعات والحضور ونشر المقررات.
- دور مندوب قابل للتخصيص على مستوى الجامعة بدل صلاحيات مدرس ثابتة.
- واجهة تحقق لهوية الطالب من مصدر الجامعة.
- جدول ربط الرقم الجامعي بمصدر الهوية وحالة التحقق.
- جدول سياسات الصلاحيات الخاصة بكل جامعة.
- جدول خصائص الجامعة القابلة للتفعيل أو الربط بنظام خارجي أو الإخفاء.
- سجل صفحات الجامعة لاختيار واجهات المنصة دون استبدال الخدمات الموجودة تلقائيًا.
- بنية نطاقات صلاحيات مرتبطة بالجامعة.
- عزل مستوى الصف في الجداول الجديدة المرتبطة بالمستأجر.
- واجهة اكتشاف بيئة الجامعة وكتالوج الوحدات.

## ما يزال مطلوبًا قبل الإنتاج

1. ربط المصادقة بمصدر الهوية الحقيقي لكل جامعة.
2. تحميل سياسات الأدوار من قاعدة البيانات بدل القيم الافتراضية.
3. تطبيق سياق المستأجر على اتصال PostgreSQL باستخدام `SET LOCAL app.current_tenant`.
4. تفعيل RLS على بقية الجداول الحالية، وليس جداول الإضافة فقط.
5. ربط المجموعات والحضور والنشر بقاعدة البيانات بدل الاستجابة التجريبية.
6. تطبيق المحرك الكامل لاكتشاف الأنظمة والصفحات عبر موصلات مصادق عليها.
7. بناء واجهات الويب والطالب والإدارة فوق هذه العقود.
8. إضافة اختبارات وحدات وتكامل تغطي حالات الطالب ونطاقات الأدوار.
9. إغلاق مسارات الإدارة الحساسة خلف مصادقة فعلية ومنع التعديل الافتراضي العام.
